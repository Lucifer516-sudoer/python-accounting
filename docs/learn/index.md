# Learn

Welcome to the python-accounting tutorial. In six short chapters you'll go
from an empty database to a full set of financial reports — the same path a
real bookkeeper walks, minus the paper.

Every chapter builds on the previous one, and every code block is complete
enough to run. By the end you'll have posted sales, purchases, taxes and
payments, cleared invoices against receipts, and printed an income
statement and balance sheet.
